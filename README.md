README är kortet i mappen. Två till fyra meningar per fråga, med ord kanjag säga när filen är stängd. Jag committar kortet med docs: och push gör att det syns i montern.

# Fråga 1 Målsvar
 Versionshantering sparar förseglade lägen/sparar lägen över tid, så att ett tidigare steg finns kvar. Utan den finns bara senaste filen. Problemet med senaste filen bara är att man inte kan se historik och skriver onsdag över måndag.

# Fråga 2 Målsvar
Arbetsytan är filen, gitt add väljer, git commit förseglar valet med en mening och status bara läser. 

Ändringar man gör i en fil hamnar som untracked files det ser vi med command git status och vil man stage changes sa kör man kommand som git add index.html om det är just den filen ändringarna gjort i. När man har stage changes så commitar vi med ett commit meddelande som är relevant. Eter det för att synca de nya uppdaterinagrna med github kör vi command git push.
